# Data validation findings (2026-10-03)

The page shows prices only (home values and rent). `report.md` is regenerated by `scripts/validate-local-data.py`,
which parses every raw file with its own code and does not import the build script. Section 6 ("Shipped data
invariants") FAILs the refresh on bad county names, CT planning-region rows, out-of-range metrics, unexpected
fields, unresolved crosswalk counties, rent counties missing from `county-geo.json`, or an inconsistent
`county-rent.json` / Housing-graph series.

## What holds up

| Claim | Evidence |
|---|---|
| The pipeline reproduces its sources | Every county's home-value % and level match raw ZHVI; rent levels match raw ZORI; county jobs match an independent QCEW re-read. |
| County rent changes are real | Zillow (SA) vs Apartment List since Jan 2025: r = 0.86 across 364 counties (sign agreement 82%). |
| County home-value changes are real for larger counties | ZHVI vs FHFA (2025): r = 0.81 for the 492 counties with ≥50k jobs. ZHVI runs about 1.5 pts below FHFA, partly because FHFA uses conforming mortgages only and leaves out jumbo-loan markets. |
| Rent tab = Rent card; Home prices tab = map | The Housing graph's latest % reproduces `county-rent.json` `pct` and the map's `hv` for every county. |

## Outliers checked and kept (real, not bugs)

- **Rent:** Taylor County TX (Abilene) +48%: all Abilene zips rose 47–60%; Apartment List does not cover Abilene. Lake Charles LA (Calcasieu Parish) +23% is confirmed by Apartment List. SF +34% is confirmed by Apartment List (+40%). Flagged counties carry the generic "unusual value" caveat and are excluded from movers lists.

## What we cannot claim

- **BLS CPI shelter and Zillow rent measure different things.** CPI covers all tenants, including existing leases; Zillow covers new listings. CPI trails market rents by about a year, which is why a metro's CPI shelter can rise while its Zillow rent falls. Both are correct; the cards say which one they show.

## Coverage

Of the site's crosswalk zips, 48% are in a county with published rent (SA since Jan 2025). Puerto Rico has data but no map shape.
